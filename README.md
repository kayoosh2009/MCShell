# MCShell

Open-Source free Minecraft launcher for Linux

---

This project was created through a collaboration between AI and my own efforts. All correspondence with the AI (in Russian) will be available in a separate .md file so you can be sure that I didn't just hand over all the work to the neural network, as some other "vibe-coders" do.

The project is written in Rust and Slint. I considered using web technologies (HTML/CSS), but due to Tauri's poor performance on certain Linux kernels, I decided to tackle Slint instead. While struggling with Slint, I've also decided to create a custom editor for it.
