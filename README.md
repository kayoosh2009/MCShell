# MCShell

MCShell is a fully offline launcher for Minecraft that lets you easily and quickly enjoy the game called Minecraft.

The launcher is written entirely in Rust, which allows it to launch fast and take up a minimal 3.12 MB. It also has a cool console interface.

![MCShell Preview](https://i.pinimg.com/736x/56/b5/28/56b528413421f8f261cb3332693be45c.jpg)

It may seem like the launcher is incapable of anything, but you are greatly mistaken — here is a list of what the MCShell launcher has:
- Skin changing (inside the launcher) — you can set any skin you want
- Mods / Texture packs — you can install any mods and textures
- Any versions and Fabric — you can download any version of Minecraft, including Fabric
- Mod and texture browser — a built-in installer for add-ons
- Fast and almost instant Minecraft launch
